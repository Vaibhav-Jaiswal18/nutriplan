# 🥗 NutriPlan

> Personalized nutrition and daily diet planning web application.

NutriPlan is a full-stack nutrition planning application that generates personalized daily nutrition targets and meal plans based on a user's body measurements, activity level, fitness goal, and dietary preference.

The application calculates BMI, BMR, TDEE, daily calorie targets, macronutrients, hydration requirements, and generates a personalized meal plan.

## ✨ Features

- 🔐 User registration and login
- 🔑 JWT-based authentication
- 🛡️ Protected routes
- 📏 BMI calculation
- 🔥 BMR calculation
- ⚡ TDEE calculation
- 🎯 Goal-based calorie targets
- 🥩 Personalized protein, carbohydrate, and fat targets
- 💧 Personalized water requirements
- 🥗 Vegetarian and non-vegetarian meal plans
- 🍽️ Automated daily meal generation
- 💾 Save diet plans to PostgreSQL
- 📋 View previously generated plans
- 📊 Detailed nutrition breakdown
- 📱 Responsive user interface
- 🚀 Production deployment

```text

       ↓

       ↓

Calculate BMI
       ↓
Calculate BMR
       ↓
Calculate TDEE
       ↓
Calculate Target Calories
       ↓
Calculate Macronutrients
       ↓
Calculate Water Requirement

       ↓
